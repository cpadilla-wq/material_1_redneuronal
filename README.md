# Propagación hacia adelante en una red neuronal simple
Cristian David Padilla Peinado 
Hola
Este repositorio contiene un cuaderno de Jupyter que implementa la propagación hacia adelante (forward propagation) en una red neuronal totalmente conectada.

## Requisitos

- [Anaconda](https://www.anaconda.com/download) o [Miniconda](https://docs.conda.io/en/latest/miniconda.html) instalado.

## Configuración del ambiente

1. Crea un ambiente de conda con Python (por ejemplo, Python 3.11):

   ```bash
   conda create -n rnap python=3.11
   ```

2. Activa el ambiente:

   ```bash
   conda activate rnap
   ```

3. Instala las dependencias del proyecto con pip, usando el archivo `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

## Ejecutar el cuaderno

Con el ambiente activado, inicia Jupyter Lab desde la raíz del repositorio:

```bash
jupyter lab
```

Esto abrirá una pestaña en tu navegador. Desde ahí, abre el archivo `A_propagacion_hacia_adelante.ipynb` y ejecuta las celdas en orden.

## Desactivar el ambiente

Cuando termines, puedes desactivar el ambiente de conda con:

```bash
conda deactivate
```
